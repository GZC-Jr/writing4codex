# IEEE Journal LaTeX Paper Standards

> **Note**: Applies to `main.tex` of IEEE Transactions / journals (T-PAMI, TIP, TII, TIM, RA-L) and equivalent top-tier journals.
> Conference papers (CVPR/ICCV/ECCV/NeurIPS) use a different class — see `latex-ieee-conference skill` when applicable.

## Core Principle

IEEE journal papers follow the supplied venue template and its document class.
Standard IEEEtran modes generate section and subsection numbering automatically.
Write `\subsection{Overall Architecture}` without a manual `A.` prefix, letting the class supply the rendered number or letter.
Inspect any venue-specific class modifications before changing heading conventions.

## Constants

- **MAIN_TEX**: `main.tex` - Single-file root of an IEEE-style paper.
  Everything below targets this file.
- **CLASS**: `IEEEtran` - Document class bundled separately from `\documentclass{}`.
  Do not substitute `article`.
- **BIB_FILE**: `references.bib` - BibTeX source for all `\cite{}` calls.
- **SECTION_PATTERN**: `UPPERCASE_TITLE` - `\section{Introduction}` renders as `I. INTRODUCTION` automatically.
  Capitalize manually if needed.
- **SUBSECTION_PATTERN**: `\subsection{<Title>}` with numbering supplied by the actual class.

## Rules

### ✅ DO

- Use `\documentclass[lettersize,journal]{IEEEtran}` for journal submissions
- Define `\title{}` and `\author{}` in the preamble and place `\maketitle` as required by the venue template.
- Wrap the Abstract inside `\begin{abstract}...\end{abstract}` before `\begin{IEEEkeywords}`
- Write subsection title text without a manual letter or number prefix.
- Write normal section titles in mixed case and let the class render them.
  Let the bibliography mechanism produce its own reference heading.
- Define notation in one place (a Preliminaries subsection or `notation.tex`) and reference it consistently
- Use `\label{sec:...}` / `\label{fig:...}` / `\label{eq:...}` immediately after the corresponding `\caption{}` or `\section{}` / `\begin{equation}`

### ❌ AVOID

- Do not switch to `article` class or rewrite the preamble to mimic conference templates
- Do not override IEEEtran's Roman-numeral-to-uppercase conversion by writing `\section{INTRODUCTION}` manually
- Do not redefine `\maketitle`, `\section`, or other IEEEtran-managed commands
- Do not inline BibTeX entries.
  All entries must live in `{BIB_FILE}`
- Avoid first-person contribution and author-action statements wherever possible, preferring object-centered passive forms such as `A method is proposed` or `A module was designed`.
- Do not write `\subsection{A. Overall Architecture}` in an automatically numbered class, as it duplicates the displayed prefix.

## Patterns

### Section + Subsection Labeling

```latex
% ✅ Good: plain title text, with numbering generated by the class.
\section{Introduction}
\label{sec:introduction}

\section{Related Work}
\label{sec:related}

\subsection{Method Family A}
\label{sec:method_family_a}

\subsection{Method Family B}
\label{sec:method_family_b}

\subsection{Method Family C}
\label{sec:method_family_c}

\section{Methodology}
\label{sec:method}

\subsection{Overall Architecture}
\label{sec:overall_arch}

\subsection{Module A}
\label{sec:module_a}

\section{Dataset}
\label{sec:dataset}

\subsection{Image Collection}
\label{sec:image_collection}

\subsection{Analysis of Challenges}
\label{sec:dataset_challenges}
```

```latex
% ❌ Bad: manually adding the letter duplicates the class-generated prefix.
\section{Methodology}
\subsection{A. Overall Architecture}
```

```latex
% ❌ Bad: label placed before \section, breaks cleveref and PDF bookmarks
\label{sec:introduction}
\section{Introduction}
```

### Figure Placement

```latex
% ✅ Good: [!t] requests top placement; caption precedes label; IEEEtran order
\begin{figure}[!t]
  \centering
  \includegraphics[width=\linewidth]{figures/framework.pdf}
  \caption{Overall framework of the proposed method.
  The encoder integrates task-relevant information into a module to explicitly assign specific feature encoding to different requirements.}
  \label{fig:framework}
\end{figure}
```

```latex
% ❌ Bad: label before caption; no placement hint; full-textwidth in a two-column paper
\begin{figure}
  \centering
  \includegraphics[width=\textwidth]{figures/framework.pdf}
  \label{fig:framework}
  \caption{Overall framework of the proposed method.}
\end{figure}
```

### Equation Referencing

```latex
% ✅ Good: equation labeled so future prose can \cref{eq:foo}
\begin{equation}
  X_{temp} = (1 - \lambda \cdot \mathcal{G}) X_0 + (\lambda \cdot \mathcal{G}) X_{new}
  \label{eq:template_update}
\end{equation}
```

## Preamble Skeleton

```latex
% ✅ Good: minimal preamble for an IEEE journal paper
\documentclass[lettersize,journal]{IEEEtran}
\usepackage{amsmath, amssymb}
\usepackage{graphicx}
\usepackage[caption=false,font=footnotesize]{subfig}
\usepackage{booktabs}
\usepackage{cleveref}
\usepackage{algorithm}
\usepackage{algorithmic}

\title{Your Title Here}

\author{
  Author Name, \IEEEmembership{Member, IEEE,}
  \thanks{Manuscript received ..., revised ..., and accepted ...}
  \thanks{... corresponding author: ...}
}

\begin{document}
\maketitle

\begin{abstract}
...
\end{abstract}

\begin{IEEEkeywords}
keyword1, keyword2, keyword3
\end{IEEEkeywords}
```

## Benefits

- **Compile safety**: Sticking to `IEEEtran` defaults avoids silent class/option conflicts that break PDF output
- **Reviewer-friendly**: Clean, predictable sectioning lets reviewers jump straight to equations or figures
- **Reusability**: A canonical preamble + bibliography can be cloned across submissions with minimal edits
- **Heading consistency**: Class-generated numbering avoids duplicate or stale prefixes.

## Remember

- `IEEEtran` is opinionated.
  Override it as little as possible
- `\section{Introduction}` (mixed case), class renders as `I. INTRODUCTION`
- `\subsection{Overall Architecture}` with class-generated numbering
- Labels go *after* the thing they label, never before
- The preamble is shared ground — coordinate package changes with co-authors before editing
